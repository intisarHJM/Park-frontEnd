# 🌳 Central Landing Park | Frontend

Welcome to the frontend of **Central Landing Park**, a project developed during a park-themed Stackathon. This application provides a modern, interactive user interface for park visitors, built with React and Vite.

## 🔗 Backend Repository
To run this application with full data functionality, you must also have the backend server running:
**[Park Backend API Repository](https://github.com/intisarHJM/Park-backEnd.git)**

---

## 🚀 Project Overview
The **Central Landing Park** frontend focuses on a seamless user experience, allowing users to visualize park layouts and interact with real-time data provided by our Express API.

### ✨ Key Features
* **Interactive Park View:** A visual representation of park rides and attractions.
* **Seamless API Integration:** Uses Axios to communicate with the Node/Express backend.
  
---

## 🛠 Tech Stack
* **Build Tool:** Vite (for fast development and optimized bundling)
* **Library:** React.js (.jsx)
* **Routing:** React Router DOM
* **State Management:** React Hooks (`useState`, `useEffect`)
* **API Communication:** Axios
* **Styling:** Custom CSS3 with **Flexbox** ---
